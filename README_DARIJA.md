# EZ-STORE R5 — تحديث واجهة الزبون والمخزون

**باش تجرب النسخة الصحيحة:** افتح `http://localhost:3200` ماشي `3000` (النسخة القديمة عندك ممكن مازالت خدامة على 3000).

1. فك ZIP داخل **مجلد جديد** ماشي فوق القديم.
2. إذا عندك حسابات مخزنة، انسخ **نفس** `.env` ومجلد `data` من المجلد القديم إلى الجديد. ضروري يبقاو مجموعين باش فك تشفير الحسابات يبقى خدام. **خد Backup قبل أي تغيير**.
3. شغل `START_EZSTORE.bat` (Node.js 22.13+). كلمة سر Admin تولد أول مرة فقط إلى ما كانش `.env`. احتافظ بها.
4. افتح `http://localhost:3200` والـ Admin فـ `http://localhost:3200/admin`.
5. فـ Admin > Add accounts كاين دابا **حذف الحسابات بالعدد** تحت زر الإضافة مباشرة. اختار المنتج، كتب العدد، ثم وافق على التأكيد. الحذف نهائي فقط من الحسابات available.
6. باش تتأكد من النسخة: `http://localhost:3200/api/health` خاصها ترجع `EZ-STORE-R5-2026-11-02`.

## شنو تصلح؟
- ما كاينش زر ♙ ديال Admin ولا الروبو الجانبي فواجهة الزبناء؛ السيرفر كيمنع الوصول لمعلومات المخزون بلا جلسة Admin.
- الحذف الجماعي ولى قريب من إضافة الحسابات وكيستخدم نفس اختيار المنتوج.
- منع اختلاط النسخة القديمة (`3000`) والجديدة (`3200`) من ملف التشغيل.
- واجهة شراء USDT TRC20؛ ما كاينش PayPal checkout فهاذ النسخة.

## واش جاهز للبيع الحقيقي؟
**البرنامج كيتشغل محلياً؛ ماشي موقع منشور لزبناء الإنترنت.** باش يستقبل طلبات حقيقية خاصك: تضبط `USDT_TRC20_ADDRESS` و `SMTP_HOST/USER/PASS/MAIL_FROM` فـ `.env`، تختبر إرسال البريد، تضيف مخزون خاصك، وتنشره على استضافة Node.js بدومين HTTPS مستقر. **تأكيد دفع USDT يدوي** من Admin بعد التحقق من TronScan، ماشي تلقائي. هاد الأمور ما تختبروش بمعاملة حقيقية.

ما تنشرش `.env`، `data/` ولا كلمات السر فـ GitHub أو أي موقع عمومي.
